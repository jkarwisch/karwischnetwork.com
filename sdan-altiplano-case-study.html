DEPLOYMENT & INTEGRATION

SDAN / Altiplano Deployment for an Open-Access Fiber Network

Primary hands-on deployment engineering, from platform preparation through successful acceptance testing.

Project Type
FTTP Broadband Access Network Deployment and Integration
Customer Type
Open-Access Fiber Infrastructure Provider
Technologies
Nokia Lightspan FX, Altiplano, XGS-PON, Ubuntu Linux, HPE ProLiant, 100 Gbps Ethernet

Project Overview

Served as the primary hands-on deployment engineer for the installation and integration of a software-defined access network (SDAN) supporting an open-access fiber-to-the-premises (FTTP) infrastructure provider.

The project involved deploying the Altiplano management platform, commissioning a Nokia Lightspan FX optical line terminal (OLT), configuring broadband service profiles, integrating supporting network systems, and validating operational readiness.

Successful deployment required coordination with multiple technical teams, including IP routing, firewall, customer engineering, internet service provider (ISP), and operations support system (OSS) vendors.

CHALLENGE

Technical Challenges

Deployment without Internet connectivity

The upstream router had not yet been commissioned, leaving the installation environment without Internet access. This required an alternative approach to obtaining operating system updates and Altiplano installation packages.

OLT software preparation

The OLT required a software image change to support the planned Lightspan deployment. Preparing the platform involved updating its CompactFlash media with the appropriate Lightspan software.

Hardware troubleshooting

A failed card in the OLT chassis required troubleshooting during deployment and integration.

APPROACH

Technical Approach and Contributions

As the primary hands-on deployment engineer, responsibilities included:

  • Collaborating with engineering teams, the customer, and ISP representatives to define SDAN architecture and service requirements, including QoS, VLAN numbering, and broadband speed tiers.
  • Installing and configuring Ubuntu Linux and the Altiplano management platform.
  • Preparing installation materials and operating system updates off-site to accommodate the lack of Internet connectivity.
  • Creating an air-gapped Altiplano installation package using an authorized lab environment.
  • Updating the OLT CompactFlash media with the required Lightspan software image.
  • Commissioning and integrating the Lightspan FX OLT.
  • Creating Altiplano service profiles to support the defined network and service requirements.
  • Configuring test services and validating network connectivity.
  • Troubleshooting OLT hardware and providing on-site assistance to routing and firewall teams.
  • Executing the Acceptance Test Procedure (ATP) to validate system functionality and operational readiness.
OUTCOME

Results and Outcomes

All planned acceptance tests passed successfully following establishment of ISP connectivity and successful communication between the OSS vendor systems and Altiplano.

The deployment demonstrated the ability to overcome unexpected installation constraints, resolve platform software issues, troubleshoot access-network hardware, and coordinate integration across multiple technical disciplines.

The experience also reinforced the importance of preparing alternative installation procedures for deployment environments with limited or unavailable Internet connectivity.
