# Karwisch Broadband Consulting website

This folder contains a source copy of the current `karwischnetwork.com` single-page site with the requested Karwisch Broadband Consulting rebrand.

## Files

- `index.html` — page markup, metadata, brand copy, service descriptions, timeline, disclaimer, and footer
- `styles.css` — preserved visual design, color palette, layout, and responsive behavior

The site keeps `karwischnetwork.com`, `contact@karwischnetwork.com`, the 47-year telecommunications reference, and the confirmed technical focus: SDAN, Altiplano, ISAM, AMS, NETCONF/YANG, and RESTCONF. Unsupported PON wording was removed. Nokia trademarks are identified, and the footer states that Karwisch Broadband Consulting is independent and not affiliated with, sponsored by, certified by, or endorsed by Nokia.
